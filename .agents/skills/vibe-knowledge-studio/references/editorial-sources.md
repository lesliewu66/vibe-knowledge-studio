# 编辑方法来源登记

核查日期：2026-10-20。以下记录实际阅读层级，不把搜索摘要、作者自述、拆片报告或课堂实验混成同一种证据。链接可能随时间更新。本文为独立归纳，不转载原稿、分镜或图片。

## 实践例子的事实来源

- F1：[Harvard Physics生日问题解答](https://www.physics.harvard.edu/resource/solution46)。阅读PDF前部公式和问题区别：至少任意一对同生日，与有人和指定的自己同生日不同。
- F2：[Harvard CS50 Probability](https://cs50.harvard.edu/extension/2026/fall/psets/6/probability/)。阅读概率模型与模拟任务；采用独立、365日均匀且不计闰日的模型，不将其当现实抽样调查。
- F3：[London Museum：Harry Beck与地铁图](https://www.londonmuseum.org.uk/collections/london-stories/harry-beck-revolutionised-tube-map/)。阅读简化与连接关系部分；支持特定地铁示意图的设计取舍，不能推出“一切地图都必须撒谎”。

## 来源处理规则

方法来源决定“为什么尝试这样做”，题材来源决定“片中说法是否成立”；两个账本分开。只有搜索摘要时标摘要；作品未观看时不声称拆片。不同来源重复同一作者/样本时不算独立验证。没有证据的流量承诺不入选题评分。
