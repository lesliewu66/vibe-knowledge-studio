# Vibe Knowledge Studio

将主题制作成可核查、可预览、可修改的知识短片。此 Skill 配合本地 Vibe Studio 引擎；它本身不调用模型 API。Agent 负责研究和创作，脚本负责结构校验、确定性画面、声音和编码。

## 定位工具

若 Skill 在工程 `.agents/skills/` 下，工具根目录为向上三级；全局副本的位置记录见 `references/toolkit.md`。确认根目录有 `studio.py` 和 `engine/`。工作命令与数据约定见 [制作接口](references/workflow.md)。

## 制作方式

- 用户给出主题即开工。缺省横屏1920×1080、30fps、约2分钟、无旁白；这些可按需求调整。没有题目且用户只要求搭建工具时，使用清楚标明的原创技术演示。
- 先查一手来源，维护 `project.json` 的 sources 和 claims。每条可检验的字幕关联主张；实际阅读证据后才填写 verified、核查日期和证据摘要。程序只校验记录结构，不能认证事实。不要让模型编造文献，也不要把情绪化类比当科学推论。
- 写可在手机上读完的短句，规划每句的画面对象和实际动作。不要只做字幕背景加无关粒子。事实、类比、实测、示意须明确区分。
- 使用真实授权音乐时记录来源与许可；先分析段落和能量，再人工/Agent核对节拍。当前音频工具提供RMS、采样峰和显式BPM网格，**不具备自动可靠识别BPM或LUFS认证能力**。没有音乐可用原创程序音轨验证，不宣称达到商业配乐水平。
- 先制作覆盖关键视觉的10–30秒片段，用户授权全流程则可继续。只有用户明确要求确认时才等待；否则自行审片迭代。不要把单个模板或画风固定为所有题目的限制。
- 按分镜在项目 `scenes.js` 注册独立绘制函数。`t` 为全片时间，`lt` 为本镜时间。每帧由时间决定，不使用 Date.now、未固定种子的随机数或跨帧积分。外部图片须预加载并验证来源；现有演示不含图片加载器，需实现后再使用。
- 运行结构校验和 review；查看接触表，对重点转场额外检查或渲染短片。sample QA 不等于逐帧人工审片。字幕过长、遮挡、跳切需要实际修复。
- 渲染完整MP4、解码核验，并交付源码、字幕、来源、分镜、封面和发布草稿。记录哪些确实检查过、是否听过最终音轨。工具未提供音频回放时不要声称听感通过。
- 用户要新画风、复杂机制或新图形时扩展 scenes.js。不能把仅改标题的卡片模板当成定制知识视频。

## 实际能力边界

本套已实现：本地预览、时间跳转、确定性抽帧、接触表、字幕宽度检查、结构来源校验、SRT/分镜/研究导出、原创基础配乐、导入音乐、单声道分析、片段/整片H.264+AAC输出与解码验证。事实核查与选题设计依赖调用本 Skill 的联网 Agent。没有独立无人值守选题发布服务、TTS、自动爆款预测或自动版权判定。
