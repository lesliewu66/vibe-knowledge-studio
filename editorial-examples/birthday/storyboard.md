# 字幕与分镜初排（120秒）

这是独立编写的前期练习，没有照搬参考片的字幕或独特镜头。每行两拍，暂各5秒；句子不长不等于足够读懂，实际样片需调整。人物头像与日期位置全片保留身份一致性；蓝色为指定人物，金色强调当前比较，红色仅标发现同生日。音乐在关键计算时减弱。

| 时间 | 字幕（两拍以 / 分隔） | 入镜、变化与出镜 | 观众观察与允许推理 | 注意和风险 |
|---|---|---|---|---|
| 0–10 | 23个人里，会不会有人同一天生日？ / 先看一个简化模型。 | 房间进入23个头像；暂停预测。随后出现365日日历与模型条件，暂不抽生日 | 明确问题是“任意一对”；知道不是在报告真实人口 | 条件占独立画面：日期等可能、相互独立、忽略闰日；不在激烈动画中塞小字 |
| 10–20 | 算出来的概率，超过一半。 / 但这不是说，有人和你同一天生日。 | 出现“>50%”，保留23头像；镜头锁定一位蓝色人物 | 两句话涉及不同任务，尚待解释 | 不提“命中注定”；50.7%留待计算揭晓 |
| 20–30 | 只找和你同一天的人，是22次比较。 / 换一个任务：任何两个人都算。 | 只点亮蓝色人物到其他22人的线，再收起；同一批头像保留，改为两两检查 | 比较集合发生变化，而非同一概率莫名增大 | 线分批出现；不一次铺满253条线 |
| 30–40 | 四个人，已经有六对。 / 23个人，共有253对。 | 临时聚焦前四头像逐对编号1–6；拉回23头像，显示n(n−1)/2与253 | 配对数增长快；这仍只是直觉辅助 | 量尺明确标“对”；不把253/365标成概率 |
| 40–50 | 配对多，解释了直觉为何容易失准。 / 精确概率，还得另外算。 | 冻结配对图，数字移入“比较次数”框；旁边保留未解的概率框 | 观察与证明的责任被分开 | 此处有意不新增装饰动作；留阅读时间 |
| 50–60 | 换个方向：先算谁都没撞上。 / 第二个人，要避开第一个人的日期。 | 日历出现第一个生日；第二人可选区域排除一日，显示364/365 | 通过补事件计算；第二人在假定模型中有364个安全日期 | “全部不同”作为持续状态标签，不让观众误以为直接在算碰撞 |
| 60–70 | 前两人不同，第三人就要避开两天。 / 后面的人，继续避开已占的日期。 | 前两日期先明确不同；第三人安全格为363；之后逐步增加人数 | 看见条件概率的前提，以及乘积各因子的意义 | 不演一条具体生日路径就宣称总体概率；图是条件计数示意 |
| 70–80 | 23个人都不同，约有49.3%的概率。 / 至少一对相同，就是剩下的50.7%。 | 公式从短乘积扩展为365/365×364/365×…×343/365；同一100%条分成两部分 | “全部不同”和“至少一对相同”互补 | 公式必须有足够观看时间；过密则加时，不为了120秒压缩 |
| 80–90 | 如果只查其他22人和你呢？ / 同一模型下，约是5.9%。 | 蓝色人物回场；22条指定连线与任意配对图并排，分别标5.9%、50.7% | 相同人数不同事件，概率不同 | 两边假设相同；不要将“其他22人”误写为包含自己22人 |
| 90–100 | 也可以反复模拟很多个班级。 / 再看多少个班级出现了同生日。 | 批量模拟的结果格逐个出现，动态累计matches/trials，读取math-check.json | 有限模拟频率可用作观察和校验 | 明标“模拟”；不伪造真人样本；不将频率强制收敛到50.7% |
| 100–110 | 这不保证，你的班里一定有一对。 / 现实中的生日，也未必均匀独立。 | 回到一个没有重复生日的示意班级，随后重现模型条件卡 | 理解概率事件与模型边界 | 无依据不声称真实概率精确变化多少 |
| 110–120 | 再问一次：你刚才比较的是谁和谁？ / 有人和你相同，还是任意两人相同？ | 开头23人回场，两套连线先隐藏；给观众选择，再并列显示任务名；片尾来源 | 迁移检验目标是辨清事件，不只记住23与50.7 | 末句不接人生鸡汤。片尾参考需可读；如不够，延长片尾 |

## 样片前需要解决的内容

先做50–80秒的条件计算镜头，确认日历、人数与乘积的关系能看懂，再制作0–30秒开场。数学确认通过不代表这两段视觉效果通过；本轮没有渲染新样片。
